# MoneyLens

Веб-приложение для учёта личных финансов: операции, счета, бюджеты, цели накоплений и сводная аналитика. Пет-проект с React-интерфейсом и отдельным Node.js API.

**Стек:** React 19, React Router 7, Vite 7, SCSS, Node.js.

## Возможности

- Учёт доходов, расходов и переводов между счетами.
- Бюджеты по категориям и отслеживание их использования.
- Цели накоплений с регистрацией взносов.
- Дашборд с разбивкой операций, недельной статистикой и расчётным прогнозом.
- Регистрация, вход и данные пользовательского профиля.

## Запуск

Нужны Node.js, совместимый с Vite 7, и npm. Из корня проекта:

```bash
npm ci
npm run dev:all
```

Команда запускает API и Vite одновременно. Откройте адрес, который выводит Vite. API по умолчанию использует порт 3001; сервер читает переменную `API_PORT`.

Отдельные процессы:

```bash
npm run api
npm run dev
```

Сборка интерфейса: `npm run build`. Предпросмотр: `npm run preview`. Для операций с данными API должен работать отдельно. Скрипт совместного запуска называется `dev:all`.

## Архитектура

- `src/pages/` — страницы операций, счетов, бюджетов, целей и аналитики.
- `src/contexts/` — состояние авторизации и финансовых операций.
- `src/services/` — запросы к API.
- `server.js` — HTTP API и файловое хранение данных.
- `src/styles/` — SCSS.

## Ограничения

Демонстрационный проект с файловым хранением данных. Production-безопасность авторизации и многопользовательская эксплуатация не подтверждены. Для демонстрации используйте тестовые данные. Расчёты дашборда являются частью интерфейса проекта.
